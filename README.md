# HR Analytics Dashboard

## Project Overview
This project is an HR Analytics Dashboard developed using Power BI to analyze employee attrition, workforce demographics, job satisfaction, and department performance.
Dataset: Sample HR Analytics Dataset (Portfolio Project)

## Tools Used
- Power BI
- Microsoft Excel
- Power Query
- DAX

## Project Workflow

1. Data Collection and Understanding
   - Explored HR dataset containing employee demographics, attrition, income, and job role information.

2. Data Cleaning and Transformation
   - Used Power Query to clean and prepare data for analysis.

3. Data Modeling
   - Created relationships and structured data model for reporting.

4. DAX Calculations
   - Developed measures for Attrition Rate, Employee Count, Satisfaction Metrics, and other KPIs.

5. Dashboard Development
   - Designed interactive Power BI dashboard with slicers, KPI cards, charts, and drill-down analysis.

6. Insights Generation
   - Identified key factors influencing employee attrition and workforce trends.

## Business Insights

- Attrition varies across departments and job roles.
- Work-life balance impacts employee retention.
- Promotion history influences attrition patterns.
- Income groups show different retention trends.
- HR teams can use these insights for workforce planning and retention strategies.
